# Telegram-бот: заявки в Google Таблицу

Бот принимает заявки от клиентов, и каждая заявка сразу появляется
новой строкой в Google Таблице. Владелец получает уведомление в Telegram.

## Возможности
- Пошаговая анкета: имя, телефон (кнопкой «Отправить мой номер»), услуга, комментарий
- Проверка телефона, сводка перед отправкой
- Запись в Google Таблицу: дата, данные клиента, ник в Telegram, статус
- Заголовки таблицы создаются автоматически (жирные, закреплённые)
- Уведомление владельцу о каждой заявке, команда `/table` — ссылка на таблицу
- Если таблица недоступна, заявка не теряется: сохраняется в резервный CSV
- Услуги и колонки настраиваются в `config.py`

## Запуск
1. `pip install -r requirements.txt`
2. Создайте Google Таблицу → Расширения → Apps Script, вставьте код из `apps_script.gs`
   и впишите свой секретный ключ
3. Начать развёртывание → Веб-приложение, доступ «Все» → скопируйте ссылку /exec
4. Скопируйте `.env.example` в `.env` и заполните (ссылка, ключ, токен)
5. `python sheets.py` — проверка таблицы, затем `python bot.py`

## Технологии
Python, pyTelegramBotAPI, requests, Google Apps Script. Google Cloud не нужен.
